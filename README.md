
# PW2-TP1 — Pokédex

Trabajo práctico N°2 de **Programación Web**.

Sitio web tipo Pokédex con listado, búsqueda y panel de administrador (alta, baja y modificación de pokémon).

## Tecnologías

- PHP
- MySQL / MariaDB
- HTML + Bootstrap 5
- Sin AJAX (toda la lógica del lado del servidor)

## Funcionalidades

- Listado de pokémon en la página principal
- Búsqueda por nombre, tipo o número
- Página de detalle de cada pokémon
- Login de administrador con sesiones
- ABM completo para el admin (alta, baja, modificación)
- Subida de imágenes al servidor
- Diseño responsive

## Instalación

1. Copiar la carpeta `pokedex/` adentro de `htdocs/` (XAMPP) o equivalente.
2. Abrir phpMyAdmin → pestaña **Importar** → seleccionar `pokedex.sql` → Continuar.
3. Entrar a `http://localhost/pokedex/` en el navegador.
